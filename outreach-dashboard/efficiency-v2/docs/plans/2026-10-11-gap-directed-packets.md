# Gap-directed research packets

Preserve bounded country, industry, role, product keywords and a 240-character
description in the existing ten-row preflight packet. Previously these were
discarded, requiring another provider-file read during research. Emit one
research-only task per returned candidate: existing cached source/contact leads,
conflicts, missing leads, and the mandatory live checks. Never invent geography,
source URLs, scores or buyer intent. A primary-source failure is recorded once
and the candidate parked by the existing cache guard.

No new model calls, browser transport, concurrent sends, or eligibility bypass.
The packet is an execution aid, not an autonomous mail sender. Each confirmed
send is still permanently recorded before the next send. Benchmark claims are
restricted to packet size and file/context reuse, not end-to-end outreach speed.
