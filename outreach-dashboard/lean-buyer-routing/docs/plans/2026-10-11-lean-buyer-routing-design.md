# Buyer routing and compact execution packets

The observed bottleneck is low conversion from researched candidates to verified
buyer channels, not local preflight latency. Prefer evidenced buyer-role clues
for research order while preserving all candidates and canonical qualification.
An adjacent camping assortment can be relevant; identical existing SKUs are not
a new qualification requirement. Provider role keywords remain unverified hints.

The default preflight uses lean task packets with shared prohibitions rather than
repeating them twenty times. Exact identities, source URLs, conflict flags and all
live safety checks remain intact. Full packets remain available for diagnostics.
Research stays bounded read-only; browser sends and receipt writes remain serial.
No claim of faster end-to-end sending is made without measured real receipts.
