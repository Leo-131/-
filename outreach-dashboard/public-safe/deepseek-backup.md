# Verified public-text backup API

DeepSeek Flash is configured server-side as a backup allocation for supported
public-text preparation, including summaries, translation and product-fit
wording. Credentials are held in runtime secrets and are not included in this
repository, the browser bundle or diagnostic output.

A live provider check and the existing server router returned successful model
discovery and text responses. The non-customer fixture consumed75inputtokens and
11outputtokens,86total. An identical second request used the router cache with
0additionaltokens. This is a measured fixture, not a cost-savings percentage or
a global spending limit.

Forty-five focused model-routing and access-flow checks passed. Credential
screening now covers both current public facts and all submitted chat-history
messages. Existing user isolation, same-origin access, concurrent-request
coalescing, limits, sanitized failures and evidence-based sending rules remain.

DeepSeek API usage draws on its independent provider balance. It does not share
or extend the current Codex conversation's subscription quota. Model output does
not establish buyer identity, contact eligibility, browser access, a sent message
or improved reply rates. No raw customer database or mailbox content is attached
automatically. Runtime failures do not silently invoke another paid provider.
